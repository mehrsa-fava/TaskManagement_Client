# Roles

Attach one role when the task matches it. The skills in `.cursor/skills/` describe the steps. The docs in `docs/` describe the product.

| Role | File | Use |
|---|---|---|
| Angular frontend engineer | `ai/roles/angular-frontend-engineer.md` | A screen, service, route, or form |
| UX designer | `ai/roles/ux-product-designer.md` | Layout, states, and interaction before or during a UI change |
