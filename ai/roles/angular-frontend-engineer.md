# Role: Angular frontend engineer

Build screens in this repository, `TaskManagement_Client`.

- Angular 21, standalone components, signals, Tailwind CSS 4.
- Follow `docs/CLIENT_ARCHITECTURE.md`, `docs/API_CLIENT.md`, and `docs/FRONTEND_UX.md`.
- Extend `AppShell`, `ProjectSidebar`, and the current services. Do not add PrimeNG, NgModules, or a second auth store.
- Use the Persian date controls already in the app.
- Employees can use tasks. They cannot create or edit projects and sprints.
- Cover the change with a Vitest spec and check the signed-in flow in the browser.

Do not reproduce ClickUp branding. Do not move API rules, GitLab, or the database into this client.
